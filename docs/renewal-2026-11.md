# 리뉴얼 계획 — S&P500 적립 도우미 (2026-11)

## 목표
월급 적립으로 **S&P500 70 : 나스닥100 30**을 꾸준히 사도록 돕는 앱으로 바꾼다.
타이밍·테마 신호를 걷어내고, 계산을 정확하게 하고, 장부를 안전하게 만든다.

## 결정 사항 (2026-11-05)
- 코어 비율: S&P500 70 / 나스닥100 30
  - S&P500: TIGER 미국S&P500 (360750) 계속 매수
  - 나스닥100: 신규 매수는 KODEX 미국나스닥100 (379810, 주당 약 2.5만원). 기존 TIGER 미국나스닥100 (133690)은 나스닥 몫으로 합산
- 나머지 종목(테크TOP10·금·KODEX200·코스닥150·반도체TOP10·삼성전자·BTC)은 **보유만**: 매수 계산에서 제외, 처분은 사용자가 판단
- 2026-06 이후 공백은 실제 투자 중단 → 과거 기록 보충 없음

## 1단계 — 정확성·안전

| 항목 | 내용 |
|---|---|
| 월봉 라벨 | 거래소 시간대로 월을 매기고, 같은 달 값이 여러 개면 최신값 사용 (지금은 국내 종목이 한 달씩 앞당겨짐) |
| 기록 날짜 | KST 기준 (지금은 UTC라 오전 9시 전 기록이 전날로 저장) |
| ISA 세금 | 계좌 전체 기간 누적. 과세 대상 = 해외지수·금 ETF 매매손익(서로 통산) + 분배금. 국내주식·국내주식형 ETF 손익은 제외(보수적 추정) |
| 배당 | 현금 잔고와 총자산에 포함 |
| 투자 원칙 | 문장 파싱 대신 구조화된 점검: 손실 중 코어 매도, 감정 사유, 과다 거래 |
| 제거 | 매수 시그널·올인·패닉 모드·경고 배너, 전략 추천, DCA 주기 비교, 상관계수, 샤프·소르티노·칼마, 테마 노출, Tax-Loss Harvesting, 익절 가이드(ROI 50%) |
| 보안 | 로그인(Supabase Auth) + RLS SQL, 클라이언트 비밀번호 제거, `/api/seed` 삭제 |
| 테스트 | vitest로 계산 로직 단위 테스트 (lib 신규 코드 80% 이상) |

## 2단계 — 화면 재구성
- 탭 4개: **이번 달 / 점검 / 계획 / 기록**
- 이번 달
  - 요약: 총자산·원금·수익률. 연환산(XIRR)은 투자 12개월 이후에만 표시
  - 하락장 카드: S&P500·나스닥100이 12개월 고점 대비 -10% 이상일 때 "평소대로 매수" 안내
  - 적립 계산: 70:30 고정 분할, 정수 주, 잔돈은 다음 달로 이월, 수량·체결가 수정 가능, 비밀번호 없이 기록
  - 연속 적립 기록
- 점검: 코어 비중(목표 대비, ±5%p 벗어나면 안내), 보유만 종목, 자산 추이 차트, "S&P500만 / 70:30이었다면" 비교
- 계획: 목표(하나로 통합), ISA 세금(누적), 투자 원칙 3줄
- 기록: 투자 내역, 입금 내역, 배당, 데이터 점검, 매도 기록, 날짜별 삭제, CSV 내보내기
- 설정 DB 저장(app_settings): 폰·PC 동일. 기존 브라우저 값은 처음 한 번 DB로 옮김
- 서비스워커 캐시 버전 올림
